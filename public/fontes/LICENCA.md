# Fontes da lousa

- **Excalifont** (`Excalifont-Regular.woff2`): fonte manuscrita do Excalidraw. Os subconjuntos publicados
  no pacote `@excalidraw/excalidraw` 0.18.0 foram unidos num arquivo só.
- **Virgil** (`Virgil-Regular.woff2`): a fonte manuscrita clássica do Excalidraw, usada como reserva para
  glifos que a Excalifont não tem (², ³).
- **Cascadia Code** (`CascadiaCode-Regular.woff2`): a fonte de código do Excalidraw, criada pela Microsoft
  (https://github.com/microsoft/cascadia-code), usada nos blocos de código das aulas.

As três são distribuídas sob a SIL Open Font License 1.1
(https://openfontlicense.org), que permite usar, embutir e redistribuir as fontes junto com software,
desde que não sejam vendidas sozinhas.
