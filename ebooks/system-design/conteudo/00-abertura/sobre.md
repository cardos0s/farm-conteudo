## De onde ele vem

Este ebook nasceu do artigo **"50 System Design Concepts for Beginners in 90 Minutes"** (edição 2026), de **Arslan Ahmad**, publicado na newsletter da DesignGurus em 6 de dezembro de 2025. Nas palavras do autor:

> Quando você começa a aprender system design, a parte mais difícil não são os conceitos em si. É encontrar explicações claras num lugar só. Por isso, ter um único guia que cubra todo o essencial muda o jogo.
>
> Por isso, montei este guia para cobrir 50 dos conceitos mais importantes de system design. Pense nele como a sua referência completa para entender como sistemas reais escalam, continuam confiáveis, se comunicam e lidam com dados.
>
> Meu objetivo é passar com você por cinquenta ideias importantes, com explicações curtas e exemplos simples, para que tudo se encaixe rápido. Se você está se preparando para uma entrevista de system design, este guia é o seu recurso principal.

O artigo original está em [designgurus.substack.com](https://designgurus.substack.com/p/50-system-design-concepts-for-beginners). Todo o crédito pela seleção dos conceitos e pelas explicações originais é do autor.

## O que esta edição acrescenta

O artigo é um mapa rápido. Este ebook transforma o mapa num material de estudo:

- **A tradução fiel de cada conceito**, na seção "O essencial" de cada capítulo.
- **Tudo o que o artigo não tinha espaço para dizer**: como o conceito funciona por dentro, uma analogia, exemplos de sistemas reais, os trade-offs, o que falar numa entrevista, as pegadinhas mais comuns e três perguntas de revisão.
- **Diagramas no estilo lousa**, desenhados à mão como num quadro branco de entrevista.
- **Notas de atualização** nos pontos em que o original simplificou demais ou envelheceu.
- **Ferramentas de estudo**: uma cola com os conceitos em uma linha, flashcards, um simulado de 40 questões, um roteiro de entrevista, números de referência para estimativas, um estudo de caso completo e um glossário.

O título fala em 50 conceitos, mas o artigo traz 51. Estão todos aqui.

## Como cada capítulo funciona

Os 51 capítulos seguem a mesma estrutura, para você saber onde procurar cada coisa:

| Seção | Para que serve |
|---|---|
| Em uma frase | A ideia central, para guardar na memória |
| O essencial | A tradução fiel do trecho do artigo original |
| Aprofundando | Como o conceito funciona por dentro, com exemplo e diagrama |
| Analogia | Uma imagem do dia a dia para fixar a ideia |
| No mundo real | Sistemas e tecnologias que usam o conceito |
| Trade-offs | O que você ganha e o que você paga |
| Na entrevista | Como e quando trazer o conceito na conversa |
| Cuidado com | Confusões comuns e atualizações do original |
| Teste-se | Três perguntas com resposta, para conferir se ficou |

No fim de cada capítulo, "Conecta com" aponta os capítulos relacionados. System design é uma rede de ideias, e boa parte do aprendizado está nas ligações entre elas.
